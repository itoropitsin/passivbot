# Аудит официальных способов получить полный Bitget funding archive

Дата проверки: **18 августа 2026 года**, 13:03 UTC (Europe/Amsterdam).

Целевое окно для BTCUSDT USDT-FUTURES: `[2024-07-01T00:00:00Z, 2026-08-17T00:00:00Z]`.
При шаге 8 часов это 2 332 расчётных момента. Проверка read-only: только публичные
GET-запросы, без ключей, входа в аккаунт, заявок и переводов.

## Что проверено

### Официальный UTA API

Документация: [Get Funding Rate History](https://www.bitget.com/api-doc/uta/public/Get-History-Funding-Rate).

Запрос:

```text
GET https://api.bitget.com/api/v3/market/history-fund-rate
    ?category=USDT-FUTURES&symbol=BTCUSDT&limit=100&cursor=N
```

В документации указаны `cursor` как номер страницы с максимумом 100 и `limit` с
максимумом 100. Фактическая публичная последовательность, сохранённая в
[`funding_archive_current_audit_2026-08-18-v1.md`](funding_archive_current_audit_2026-08-18-v1.md),
составила `100, 100, 70, 0`; более старые страницы не дали данных.

Дополнительная проверка 18 августа:

- `cursor=4` — `code=00000`, 0 строк;
- `cursor=100` — `code=00000`, 0 строк;
- к запросу первой страницы добавлены `startTime=1719792000000` и
  `endTime=1786924800000` — ответ остался первой текущей страницей из 100 строк,
  а не историческим окном 2024–2026.

Это подтверждает наблюдаемый предел публичной выдачи, но не является основанием
для подстановки funding по формуле или из другого рынка.

### Официальный Classic API

Документация: [Get Historical Funding Rates](https://www.bitget.com/api-doc/classic/contract/market/Get-History-Funding-Rate).

Публичная пагинация `pageNo/pageSize` также дала `100, 100, 70, 0` и тот же
короткий горизонт. Raw-ответы и SHA-256 сохранены в текущем аудите. Второй
endpoint не добавляет строки к UTA-выдаче.

Повторная read-only проверка текущего v2 endpoint дала тот же результат для
`pageNo=1,2,3,4,10,20,100`: соответственно `100, 100, 70, 0, 0, 0, 0` строк.
Запрос `pageNo=200` вернул `code=40808` с ограничением `0 < pageNo <= 100`.
Следовательно, увеличение номера страницы не открывает более старый архив.

### Официальная страница загрузки данных

[History data download](https://www.bitget.com/data-download) перечисляет для
futures только три вида файлов: свечи, историю сделок и глубину стакана. Funding
history в каталоге загрузки отсутствует. Это полезный официальный источник для
рыночных данных, но не источник полного funding archive.

### История в интерфейсе Bitget

[Официальная инструкция Bitget](https://www.bitget.com/support/articles/12560603837210)
подтверждает, что в торговом интерфейсе можно открыть funding rate history и
выбрать период. Инструкция не предоставляет URL выгрузки, неизменяемый файл,
API-контракт или хэш полного набора строк. Поэтому просмотр в браузере пока не
считается воспроизводимым входом для historical gate.

### Дополнительный внешний вариант: Coinact

В публичной документации [Coinact Funding Rates](https://docs.coinact.gg/api/funding-rates)
Bitget указан среди поддерживаемых бирж, но endpoint
`https://api.coinact.gg/v1/funding-rate-history` требует заголовок `x-api-key`.
Документация описывает результат как исторические OHLC funding rates с настраиваемым
таймфреймом, а не как доказанный набор фактических применённых settlement-строк
Bitget с исходными ответами биржи. Ключ не запрашивался и не использовался; покупка
или получение внешнего доступа этим планом не разрешены. Поэтому Coinact — только
условный кандидат для будущей проверки покрытия и лицензии, но не текущий источник
для historical gate.

## Verdict

**Полный проверяемый funding archive публичными официальными способами не найден.**

Найденные внешние API-документы не меняют verdict: они требуют отдельный доступ
и/или не подтверждают нужную settlement-семантику и полный охват окна.

Существующий frozen input остаётся неполным: 270 строк из 2 332 ожидаемых.
`data`, historical preflight и исторический отбор остаются закрыты. Funding нельзя
восстанавливать скрытой синтетикой, прогнозом или значениями с другой биржи.

## Безопасный следующий шаг

Нужен один из двух вариантов:

1. пользователь предоставляет полный архив с подтверждённым источником и правом
   использования; или
2. пользователь отдельно разрешает получить архив у платного провайдера после
   проверки покрытия, лицензии, формата settlement-rate и стоимости.

После появления файла его нужно сначала проверить через
`tools.bitget_funding_archive`, затем продвинуть в новый execution input через
`tools.bitget_funding_promote`. Frozen input нельзя перезаписывать. До успешной
проверки 2 332 фактических строк исторический optimizer запускать нельзя.
