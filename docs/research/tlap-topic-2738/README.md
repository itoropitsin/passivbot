## Как пользоваться

- knowledge-base/ — отдельная связанная база знаний Obsidian с тематическими выводами, источниками и веткой для криптовалютного бота. Вход: [knowledge-base/README.md](knowledge-base/README.md).
- `posts.jsonl.gz` — сжатое структурированное хранилище, одна запись на сообщение; его можно распаковать командой `gzip -dk posts.jsonl.gz`.
- `chunks/` — те же сообщения в Markdown, блоками по 50 страниц, удобными для поиска и чтения.
- `indexes/authors.csv` — авторы, число сообщений и период участия.
- `indexes/links.csv` — ссылки и вложения с привязкой к исходному сообщению.
- `indexes/versions.csv` — автоматический указатель упоминаний версий.
- `manifest.json` — техническая проверка полноты и контрольная сумма выгрузки.

Исходный форум остаётся главным источником: содержание сообщений может редактироваться, а автоматические индексы могут давать лишние совпадения.
