## Как читать длинные обсуждения

Сначала читать источник, затем ответы рядом с ним в соответствующем блоке chunks/. Ответы могут уточнять, оспаривать или исправлять исходный вывод. Источник с высокой активностью автора не получает автоматически больший вес.

Для спорных вопросов искать минимум:

- исходное утверждение;
- возражение;
- повторный тест;
- разницу условий;
- итог, если он был.
